Subdomain Recon

Subdomain Enumerator

Nutzt CT-Logs, DNS-Wordlists und HTTP-Probing, um aktive Subdomains sichtbar zu machen. Der Report zeigt Status, Hosting-Hinweise und auffaellige Ziele.

Only use against domains you have explicit authorization to test.

Techniques Used

Certificate Transparency

Public CT logs via crt.sh — discovers historically issued TLS certificates for all subdomains.

DNS Brute-Force

~380 common subdomain prefixes resolved in parallel via DNS (A, AAAA, CNAME).

HTTP/HTTPS Probing

Every resolved subdomain is checked for active web services — status code, title, server header.

IP Geolocation

Unique IP addresses are mapped to country and organization.

Apex DNS Records

A, AAAA, NS, MX, TXT, SPF, DMARC and DNSSEC status of the root domain.

Risk Detection

Admin panels, CI/CD systems, databases, dev environments and more are automatically flagged.
